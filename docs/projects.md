# Проекты (0.2.11)

Раздел «Проекты» — реестр, независимый от подключений Jira и Битрикса. Слева находятся выбор папки, поиск, фильтры состояния и список проектов. Нажатие на проект открывает справа его полный статус, ответственного, сроки, описание, дополнительные поля источника и историю. На узком экране детали заменяют список; стрелка возвращает к списку. Редактор открывается отдельно.

Список получает страницы по 25 проектов с сервера; история загружается только для выбранного проекта и раскрывается порциями по 20 записей. Счётчики состояний учитывают выбранную папку и поиск. Проекты из скрытых строк и листов подключённой Google Таблицы исключены по умолчанию. Переключатель «Показать скрытые в таблице» возвращает их в выборку; история и правки при скрытии не удаляются. Папка верхнего уровня включает вложенные группы вида `Папка / Раздел` из Google Таблиц.

«Создать проект» позволяет указать название, папку, произвольный статус, состояние, ответственного, описание, дату начала, срок и ссылку. Состояние определяет видимость среди активных, завершённых и архивных проектов. Локальную папку можно изменить в редакторе. Для проектов, связанных с Google Таблицей, папка определяется листом источника.

## Импорт Excel, CSV и TSV

1. Нажмите «Импорт таблицы» и загрузите файл. Все непустые видимые листы выбраны по умолчанию; скрытые листы можно включить вручную. Скрытые строки XLSX по умолчанию пропускаются; их можно явно включить в настройках листа.
2. Для каждого листа задайте папку (изначально название листа), строку заголовков и структуру. Настройки сохраняются при переключении между листами в открытом окне.
3. Проверьте сопоставление столбцов. Типовые русские и английские заголовки распознаются предварительно; любые соответствия можно изменить. Разные листы могут иметь разные столбцы и порядок полей.
4. При необходимости задайте точные статусы завершённых проектов через запятую. Пустой список оставляет все проекты активными. Исходный текст статуса сохраняется.
5. Нажмите «Проверить импорт». Предпросмотр показывает папку, действие, название, статус, количество записей истории, ответственного и срок. Он разбит на страницы по 50 записей. Состояние отдельного проекта можно изменить.
6. Нажмите «Сохранить». До этого шага данные не записываются. Весь пакет сохраняется атомарно; повтор того же запроса не создаёт дубли. При параллельном изменении проекта потребуется подготовить новый предпросмотр.

### Структуры листов

| Структура | Как получить проекты и текущий статус |
| --- | --- |
| Одна строка — один проект | Название обязательно; остальные поля сопоставляются по желанию. |
| Проекты в строках, история в столбцах | Выберите столбцы истории. Их заголовки становятся подписями записей, непустые ячейки — историей. Последняя непустая ячейка справа задаёт текущий статус, если не выбран отдельный столбец статуса. |
| Весь лист — один проект | Задайте название проекта и столбец статуса; каждая заполненная строка становится записью истории. Можно выбрать столбец даты/подписи. Последняя заполненная строка задаёт текущий статус. |

Автоопределение — начальная подсказка. Для необычных таблиц проверьте строку заголовков, структуру и столбцы. История сохраняет порядок исходного листа, без автоматической сортировки по датам. Не выбранные для сопоставления столбцы не переносятся. Если лист содержит служебные строки, их можно явно исключить: строки без названия или жирные заголовки с единственным заполненным названием. Предпросмотр сообщает число пропусков.

### Повторная загрузка

Совпадение определяется по **папке и названию проекта**. Регистр названия и пробелы по краям не учитываются; названия папок учитывают регистр. Одинаковые названия в разных папках допустимы. Дубли внутри одной папки требуют уточнения. Переименование папки в настройке импорта меняет место поиска совпадений и может создать новые записи; для переноса уже существующего проекта используйте редактор.

Невыбранные поля существующих проектов сохраняются отдельно для каждого листа. Пустая ячейка выбранного столбца очищает поле; пустой статус заменяется на «В работе». Выбранная история заменяет предыдущий снимок истории. Обычный импорт строк без истории и ручное редактирование сохраняют существующую историю. Удаление строки из файла не удаляет проект из сервиса.

Импорт файла не перезаписывает проекты, связанные с Google Таблицей: для них используйте синхронизацию или редактор. Для независимого снимка того же материала выберите другую папку.

### Форматы и ограничения

Поддерживаются `.xlsx`, `.csv`, `.tsv`; старый `.xls` нужно пересохранить в `.xlsx`. Даты XLSX учитывают календарь 1900/1904; текстовые даты принимаются как ГГГГ-ММ-ДД, ДД.ММ.ГГГГ или ДД/ММ/ГГГГ. Формулы не выполняются, используются сохранённые значения. CSV/TSV принимаются в UTF-8 или UTF-16 с BOM.

Лимиты исходного файла: 5 МиБ, 5000 строк на лист с заголовками, 400 столбцов, 40 листов, 300 000 ячеек и 2 МиБ текста. За один импорт — до 2000 проектов; история каждого проекта — до 400 записей. Слишком большой или повреждённый файл отклоняется целиком, без молчаливого частичного импорта. Обычный предпросмотр вложений сохраняет собственные меньшие лимиты.

Файл импортируется как снимок. Фоновой синхронизации с локальным Excel нет: для обновления загрузите файл повторно. Для подключённой Google Таблицы есть отдельная [фоновая синхронизация](project-sheets-sync.md).

## Переносимость

Названия компании, отдела, папок и листов не задаются в конструкторе константами. Другой пользователь может загрузить свою книгу и настроить сопоставление в интерфейсе. Интеграции и таблицы подключаются отдельно для каждого развёртывания. Импорт не создаёт задачи в Jira или Битриксе.

Рабочие и демонстрационные проекты хранятся отдельно в SQLite. Модуль можно отключить без удаления данных. Исходный файл не сохраняется; у проекта остаётся его название как источник. Подготовка всего репозитория к публичной публикации, выбор лицензии и проверка отсутствия персональных данных — отдельная работа; универсальный импорт сам по себе этого не гарантирует.
