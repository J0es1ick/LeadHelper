# Автоматическое обновление · 0.2.12

Кнопка «Обновить» остаётся для принудительной проверки. Открытые разделы обновляются автоматически без переходов по страницам. Данные получаются через периодические запросы REST/IMAP: это не серверные push-события внешних сервисов. Периоды ниже отсчитываются после завершения запроса; к ним добавляется время ответа источника.

| Данные | Проверка |
| --- | --- |
| Открытый диалог Битрикса | 4 секунды; старая страница истории — 30 секунд |
| Список чатов | 7 секунд |
| Новости / вложенное сообщение Битрикса | 15 секунд |
| Сотрудники, отделы, файлы, календарь | 30 секунд |
| Пространства, списки и открытая страница Confluence | 30 секунд |
| Состояние приложения и уведомления | 5 секунд, в том числе в фоне |
| Задачи, почта, проекты и планы из локальной базы | 10 секунд, дополнительно при изменении ревизии задач/почты |
| Отчёт / агрегаты списаний Jira | 15 секунд |
| Новые уведомления Битрикса на сервере | 10 секунд независимо от открытого раздела |
| Задачи Jira и команда Битрикса на сервере | 1 минута |
| Списания Jira | текущая неделя на сервере каждую минуту; просматриваемые недели — с кешем 1 минута |
| Почта IMAP | по умолчанию 20 секунд; настройка `MAIL_SYNC_INTERVAL` сохраняет приоритет |
| Google Таблица проектов | серверная синхронизация каждую минуту, если подключён скрипт |

Jira загружается в пределах настроенной команды/JQL; ограничение 10 000 задач и атомарное применение выборки сохранены. Частоту проверки не следует путать с подпиской на события Jira. Более быстрые изменения из внешних сервисов могут потребовать отдельной настройки их событий и доступного callback-сервера.

У каждого раздела одновременно выполняется не более одного автоматического запроса. Скрытые разделы приостанавливают обращения к источникам; возвращение во вкладку, фокус окна и восстановление сети запускают проверку. Общее состояние продолжает обновляться для уведомлений, пока браузер позволяет фоновые таймеры. Серверные работники не зависят от открытого браузера.

Сетевые ошибки не выключают автообновление. Запросы чтения ограничены 20 секундами (Битрикс — 12); повторные неудачи увеличивают задержку до минуты в интерфейсе и до 5 минут у серверных работников Битрикса/Jira. Почта сохраняет отдельную политику повторов до 15 минут. При восстановлении успешной связи обычная частота возвращается. Черновики, выбранный диалог, открытые карточки, фильтры, страницы и положение прокрутки сохраняются. Чат прокручивается к новому сообщению только если читатель уже находился внизу.

Для ранее настроенной почты прежнее стандартное значение `60s` заменено на `20s`; собственные значения не изменяются. Применение версии требует перезапуска через `scripts/update.ps1` от Windows-пользователя, подключившего почту.
